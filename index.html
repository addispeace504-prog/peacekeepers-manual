👋Welcome to the Peace Keepers Manual

This is the master index for the Peace Keepers Crime Case Management System. The manual is organized by user type — each role has its own dedicated guide with step-by-step instructions for every feature.

ℹ️
How to use this manual
  • Find your role in the cards below and click to open your guide
  • Use the search box to find any feature across all guides
  • Print any guide for a paper copy (Ctrl + P)
  • Bookmark this page for quick access
💡
Not sure which role you have? Log in to https://www.aapskeeper.gov.et and look at the left menu. Match the menu items to the role descriptions below — the closest match is your role. Or ask your administrator.

Tier 1 — Full Access

Super Admin

Runs the entire system. Manages users, backups, activity logs, system settings, and data. Full access to everything.

19 permissions documented
Open Super Admin Guide → 🌆
Tier 2 — City-wide

City Admin

Oversees the entire city. Analyzes crime city-wide, sends SMS, manages certificates, joins discussions.

18 permissions documented
Open City Admin Guide → ⚙️
Tier 3 — Sub-city technical

Sub City System Admin

Technical admin of one sub-city. Manages users, bulk registration, encoding converter, and system overview.

11 permissions documented
Open Sub City System Admin Guide → 🏛️
Tier 4 — Sub-city executive

Sub City Admin

Executive admin of one sub-city. Approves certificates, sends SMS, submits community reports, analyzes sub-city data.

18 permissions documented
Open Sub City Admin Guide → 🏙️
Tier 5 — Sub-city view + reports

Sub City User

Views sub-city data and submits community discussion reports. No SMS, no certificates, no user management.

14 permissions documented
Open Sub City User Guide → 🔧
Tier 6 — District technical

District System Admin

Technical admin of one district. Only role that manages Identity Cards. Manages users, configures area.

11 permissions documented
Open District System Admin Guide → 📋
Tier 7 — District executive

District Admin

District operations: SMS, attendance, schedules, manage peace keepers, request certificates, community reports.

19 permissions documented
Open District Admin Guide → 👤
Tier 8 — Data entry

Staff

Registers officers, registers crimes, records attendance, requests ID cards, submits community reports.

15 permissions documented
Open Staff Guide → 📍
Tier 9 — Ketena data entry

Ketena

Same as Staff but restricted to one ketena. Registers officers, crimes, records attendance in their neighborhood.

13 permissions documented
Open Ketena Guide →
