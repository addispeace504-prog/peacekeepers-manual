👋Welcome to the Peace Keepers Manual

This is the master index for the Peace Keepers Crime Case Management System. The manual is organized by user type — each role has its own dedicated guide with step-by-step instructions for every feature.

ℹ️
How to use this manual
  • Find your role in the cards below and click to open your guide
  • Use the search box to find any feature across all guides
  • Print any guide for a paper copy (Ctrl + P)
  • Bookmark this page for quick access
💡
Not sure which role you have? Log in to https://www.aapskeeper.gov.et and look at the left menu. Match the menu items to the role descriptions below — the closest match is your role. Or ask your administrator.

Tier 1 — Full Access

Super Admin

Runs the entire system. Manages users, backups, activity logs, system settings, and data. Full access to everything.

19 permissions documented
Open Super Admin Guide → 🌆
Tier 2 — City-wide

City Admin

Oversees the entire city. Analyzes crime city-wide, sends SMS, manages certificates, joins discussions.

18 permissions documented
Open City Admin Guide → ⚙️
Tier 3 — Sub-city technical

Sub City System Admin

Technical admin of one sub-city. Manages users, bulk registration, encoding converter, and system overview.

11 permissions documented
Open Sub City System Admin Guide → 🏛️
Tier 4 — Sub-city executive

Sub City Admin

Executive admin of one sub-city. Approves certificates, sends SMS, submits community reports, analyzes sub-city data.

18 permissions documented
Open Sub City Admin Guide → 🏙️
Tier 5 — Sub-city view + reports

Sub City User

Views sub-city data and submits community discussion reports. No SMS, no certificates, no user management.

14 permissions documented
Open Sub City User Guide → 🔧
Tier 6 — District technical

District System Admin

Technical admin of one district. Only role that manages Identity Cards. Manages users, configures area.

11 permissions documented
Open District System Admin Guide → 📋
Tier 7 — District executive

District Admin

District operations: SMS, attendance, schedules, manage peace keepers, request certificates, community reports.

19 permissions documented
Open District Admin Guide → 👤
Tier 8 — Data entry

Staff

Registers officers, registers crimes, records attendance, requests ID cards, submits community reports.

15 permissions documented
Open Staff Guide → 📍
Tier 9 — Ketena data entry

Ketena

Same as Staff but restricted to one ketena. Registers officers, crimes, records attendance in their neighborhood.

13 permissions documented
Open Ketena Guide →

🚀How to Deploy This Manual on GitHub Pages

Follow these steps to host the entire manual on GitHub Pages — free, one URL, no server needed.

ℹ️
What you'll end up with A single URL like https://your-username.github.io/peacekeepers-manual/ where all 10 files live together. Users click one link and get this whole manual.

Step 1 — Download All 10 Files

Make sure you have these 10 HTML files saved in one folder:

peacekeepers-manual/ ├── index.html ← This master index page ├── super-admin-guide.html ← Part 1 ├── city-admin-guide.html ← Part 2 ├── sub-city-system-admin-guide.html ← Part 3 ├── sub-city-admin-guide.html ← Part 4 ├── sub-city-guide.html ← Part 5 ├── district-system-admin-guide.html ← Part 6 ├── district-admin-guide.html ← Part 7 ├── staff-guide.html ← Part 8 └── ketena-guide.html ← Part 9

Step 2 — Install GitHub Desktop

  1. 1
    Go to desktop.github.com
  2. 2
    Download and install GitHub Desktop
  3. 3
    Sign in with your GitHub account (or create one free)

Step 3 — Create a New Repository

  1. 1
    Open GitHub Desktop
  2. 2
    Click File → New Repository
  3. 3
    Fill in:
    • Name: peacekeepers-manual
    • Description: Peace Keepers User Manual
    • Local path: C:\Users\winta\Documents\GitHub (default is fine)
    • Initialize with README: ✅ Check
  4. 4
    Click Create Repository

Step 4 — Copy All 10 Files into the Repo Folder

  1. 1
    Open File Explorer and navigate to where you saved the 10 HTML files.
  2. 2
    Select all 10 files (Ctrl + A)
  3. 3
    Copy them (Ctrl + C)
  4. 4
    Navigate to C:\Users\winta\Documents\GitHub\peacekeepers-manual\
  5. 5
    Paste them (Ctrl + V)
  6. 6
    Verify all 10 files are in the folder alongside the README.md

Step 5 — Commit and Publish

  1. 1
    Go back to GitHub Desktop — all 10 files appear under "Changes"
  2. 2
    Type a summary in the bottom box: Add Peace Keepers user manual
  3. 3
    Click Commit to main
  4. 4
    Click Publish repository at the top
  5. 5
    UNCHECK "Keep this code private" (required for free GitHub Pages)
  6. 6
    Click Publish repository

Step 6 — Enable GitHub Pages

  1. 1
    Open your browser and go to github.com
  2. 2
    Find your repo: peacekeepers-manual
  3. 3
    Click the Settings tab (top right)
  4. 4
    In the left sidebar, click Pages
  5. 5
    Under "Source", select:
    • Branch: main
    • Folder: / (root)
  6. 6
    Click Save
  7. 7
    Wait 1–2 minutes, then refresh
  8. 8
    You'll see: "Your site is live at https://your-username.github.io/peacekeepers-manual/"
